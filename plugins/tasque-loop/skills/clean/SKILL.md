# tasque-loop の片付け

run スキルはワークツリー（ブランチ `worktree-tasque-*`）を残したまま終わる。ランの記録（`.tasque/`）は git に無視されているので、ワークツリーを消すと一緒に消える。このスキルは、記録を元のチェックアウトの `.tasque/archive/<ワークツリー名>/` に退避してから消す。

スクリプトは `${CLAUDE_PLUGIN_ROOT}/scripts/worktrees.mjs`。ワークツリーの中ではなく、元のチェックアウトのプロジェクトディレクトリで実行する。今のセッションがワークツリーの中にいるなら、先に ExitWorktree でワークツリーを残したまま抜ける。

引数: `$ARGUMENTS`

## 手順

1. `node <scripts>/worktrees.mjs` で一覧を取る。引数でワークツリー名が指定されていれば、それだけを対象にする
2. 次のように分けて人間に見せる
   - **片付けられる**: `pr.state` が `MERGED` か `CLOSED` で、未コミットの変更がない
   - **まだ片付けない**: PR が `OPEN`、または未コミットの変更がある
   - **PR がない・状態が分からない**（`pr` が `null` か `"unknown"`）: 未完のラン（`current` があるか）も添える
3. 片付けられるものについて、消してよいかを人間に聞く。返事を待つ。消してよいと言われたものだけ、1つずつ `node <scripts>/worktrees.mjs --clean <名前>` を実行する
4. PR がないものは、人間が「捨てる」とはっきり言ったものだけ `--abandon` をつけて片付ける。プッシュしていないコミットがあれば、それも消えることを先に伝える
5. 結果（消したもの、退避先、拒否されたものとその理由）を報告する

スクリプトが拒否したもの（未コミットの変更、PR が開いている、退避先がすでにある、など）は、手で消したり強制したりせず、理由を人間に伝える。
